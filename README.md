# Ernur's Portfolio

Personal developer portfolio built with React and Vite.

## Tech Stack

- React
- TypeScript
- Vite
- Redux
- i18next (EN / RU)
- Swiper
- Less

## Structure
- Home
- Projects
- Works 
- Contacts

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
